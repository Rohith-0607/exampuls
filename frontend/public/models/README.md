# Face detection model

`blaze_face_short_range.tflite` is the short-range BlazeFace model linked by Google's MediaPipe Face Detector documentation.

- Documentation: https://developers.google.com/edge/mediapipe/solutions/vision/face_detector?tab=Web
- Pinned download: https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/1/blaze_face_short_range.tflite
- SHA-256: `b4578f35940bf5a1a655214a1cce5cab13eba73c1297cd78e1a04c2380b0152f`

The model runs locally to detect face presence. It does not identify candidates or upload camera images.
